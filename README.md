## Fangle

Fangle (First-ANGLE) is a semi-realistic shader pack currently in development for **Minecraft Java Edition**, designed for ANGLE drivers with Mobile Glues Renderer.

# Device Tested

| Component | Configuration |
| --- | --- |
| Device | Snapdragon 778G / Adreno 642L |
| OS | Android 14 |
| RAM | 8 GB |
| Launcher | Zalith Launcher: 2.7.2 |
| Renderer | MobileGlues: 2.0.0 |
